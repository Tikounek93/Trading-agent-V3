# Trading Agent v3 documentation

This directory contains durable project documentation. It describes the
architecture, module boundaries, contracts, tests and repeatable operating
procedures.

## Documents

- `architecture.md` - system purpose and information flow.
- `module-map.md` - current v3 modules and planned boundaries.
- `contracts.md` - rules for contracts and module hand-offs.
- `testing.md` - test placement, test types and verification rules.
- `operations.md` - local operation of the source-intake slice.
- `development-process.md` - change workflow, Atlas, GitHub and release gates.
- `decisions/` - durable decisions that affect the project direction.

Generated logs, downloaded source data, temporary files and one-off
experiments do not belong in this directory.
